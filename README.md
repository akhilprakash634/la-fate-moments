# La Fête Moments — Next.js

Premium, portfolio-first event moments website.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Replace demo images

The homepage currently uses Unsplash demo photography. Replace the URLs in:

`components/Moments.tsx`

and the hero image in:

`components/Hero.tsx`

with the client's actual event photographs.

## Brand colors

- Coral: #F16F63
- Ink: #171717
- Warm white: #FFFDFC
- Soft coral: #FCE4E1
- Neutral: #F7F4F2
